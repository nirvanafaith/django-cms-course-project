# PostgreSQL CMS 人工验收流程

## 1. 前置条件

启动 Compose Web 服务，确认 `/health/live/` 与 `/health/ready/` 成功。验收使用匿名窗口、普通用户和管理员三种状态；密码由当前环境变量设置，不写入本流程。

## 2. 公开功能

1. 访问 `/`，确认本地校名标识、五张本地轮播图、语义分区、页脚声明和无横向滚动。
2. 在 `/search/` 分别执行题目、日期、栏目查询，再执行三条件组合；确认结果、错误提示和分页条件保留。
3. 打开文章详情，确认已发布内容可见；草稿和不存在主键均得到公开不可见结果。
4. 在 1440px、768px、375px 验证导航、轮播暂停/前后切换/方向键、移动菜单和图像比例。

## 3. 身份与管理

1. 匿名页面显示登录，不显示后台入口。
2. 普通用户登录、退出，确认无后台入口且访问 `/admin/` 不获得管理权限。
3. 管理员登录，确认前台显示管理入口，进入 `/admin/`。
4. 创建、编辑、发布、撤回和删除一篇测试文章；确认公开可见性变化。
5. 创建栏目、尝试删除含文章栏目并确认阻止；删除空测试栏目。
6. 修改用户普通/管理员角色并确认前台导航与 Admin 权限同步。
7. 在管理审计和系统日志页筛选记录，确认只读边界和敏感数据缺失。

## 4. 已执行结果（2026-08-15）

| 场景 | 实际结果 |
| --- | --- |
| 匿名与本地素材 | 首页无横向滚动，校名和轮播图片本地加载；匿名显示登录，不显示后台入口 |
| 公开查询 | 标题“交通”返回 5 篇；日期 2026-08-01 至 2026-08-31 加栏目 1 返回 1 篇 |
| 普通用户 | `student` 登录后显示退出、不显示后台；访问 `/admin/` 重定向到管理登录；退出后会话结束 |
| 管理员与角色 | `CTX` 显示管理入口并进入后台；`visitor` 被临时提升为管理员后可进入后台，随后还原为普通用户 |
| 文章与栏目 CRUD | 临时文章草稿公开查询为 0，发布后为 1；文章删除和空栏目删除成功；含文章栏目删除页列出受保护文章并拒绝删除 |
| 日志 | 系统日志按 `request.complete` 与状态码 200 筛选；审计页面没有新增入口，保持只读 |
| 响应式与轮播 | 1440×1000、768×1024、375×812 无横向溢出；375px 菜单为 44px，展开状态正确；轮播下一张后方向键返回第 1 张并更新状态文本 |
| 依赖故障 | 分别停止 PostgreSQL、Redis 后 `/health/ready/` 返回 503；恢复后返回成功 |
