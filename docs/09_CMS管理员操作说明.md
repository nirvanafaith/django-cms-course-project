# CMS 管理员操作说明

## 1. 登录与角色

管理员通过前台“登录”或 `/admin/` 使用管理员账号 `CTX` 登录，固定密码为 `1234`。普通账号 `student`、`visitor` 的密码由 `DEMO_USER_PASSWORD` 提供，只能浏览公开内容。

## 2. 用户管理

在“认证和授权”中创建或编辑用户。角色选择“普通用户”会同步关闭 staff 和 superuser；选择“管理员”会同步开启二者。停用账户会拒绝其后续登录。管理员之间可互相降级或删除，因此提交前必须核对目标用户和影响范围。

## 3. 栏目管理

在“内容管理 -> 栏目”创建、搜索、编辑栏目。列表文章数由聚合查询提供。删除前确认栏目没有文章；含文章栏目受数据库 `PROTECT` 约束，不能删除，必须先迁移或删除文章。

## 4. 文章管理

在“内容管理 -> 文章”填写标题、正文、栏目、作者、发表时间和发布状态。标题或正文不能只包含空白。新文章默认草稿；勾选发布后才会进入公开页面。列表支持题目搜索、栏目/状态/日期筛选和日期层级；批量操作可设为已发布或草稿，并生成 Django 管理审计记录。

## 5. 日志查看

- Django Admin 管理日志记录用户、对象和动作，页面只读。
- “系统日志”页面最多读取近期 5000 条 JSONL 事件，可按日期、级别、事件、状态码和请求 ID 筛选；页面不提供编辑或删除入口。
- 不在日志、截图或问题单中粘贴密码、Cookie、令牌或完整访问地址。

## 6. 发布后核对

使用匿名窗口确认发布文章出现在 `/`、`/search/` 和详情页；草稿应返回公开不可见结果。编辑完栏目或文章后检查管理审计，并在遇到异常时收集不含敏感数据的日志时间、请求 ID 和操作步骤。
