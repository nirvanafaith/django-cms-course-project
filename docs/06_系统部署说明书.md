## 2. 安装步骤（全新环境）

### 2.1 获取源码

```bash
git clone <你的仓库地址> cms_site
cd cms_site
```

（若用压缩包交付：解压后进入项目根目录，目录内应有 `manage.py`。）

### 2.2 创建并激活虚拟环境

```powershell
# Windows
python -m venv .venv
.\.venv\Scripts\activate        # PowerShell 激活
```

### 2.3 安装依赖

```powershell
pip install -r requirements.txt
```

### 2.4 数据库初始化与迁移

```powershell
python manage.py makemigrations content   # 首次生成迁移（正常会提示 No changes 或生成文件）
python manage.py migrate                  # 建表（sqlite 自动创建 db.sqlite3）
```

### 2.5 导入演示数据（二选一）

```powershell
# 方式 A：种子命令（推荐，可重复执行、数据可复现）
python manage.py seed_data

# 方式 B：fixtures 加载
python manage.py loaddata content/fixtures/demo.json
```

### 2.6 创建默认账号（管理用户）

```powershell
python manage.py createsuperuser
# 按提示输入：用户名 admin / 邮箱（可空）/ 密码 admin123456（示例，验收后请修改）
```

**默认账号（演示用）**

| 角色 | 用户名 | 密码 | 权限 |
| --- | --- | --- | --- |
| 管理用户 | admin | admin123456 | 后台全部管理（is_staff + is_superuser） |

> 生产/提交前务必修改密码；此账号仅用于助教快速验收。

### 2.7 启动

```powershell
# 开发模式（localhost）
python manage.py runserver

# 局域网模式（便于演示，0.0.0.0 需配置 ALLOWED_HOSTS）
python manage.py runserver 0.0.0.0:8000
```

浏览器访问：
- 前台首页：http://127.0.0.1:8000/（栏目导航、最新文章、三种查询）
- 后台管理：http://127.0.0.1:8000/admin/ （用 admin 账号登录）

## 4. 工程配置要点（settings.py）

| 配置项 | 开发值 | 生产建议 |
| --- | --- | --- |
| DEBUG | True | False（环境变量控制） |
| SECRET_KEY | 默认 dev 值 | 从环境变量 `os.environ["DJANGO_SECRET_KEY"]` 读取 |
| ALLOWED_HOSTS | `["127.0.0.1", "localhost"]` | 部署机 IP/域名 |
| LANGUAGE_CODE | `zh-hans` | 同 |
| TIME_ZONE | `Asia/Shanghai` | 同 |
| DATABASES | sqlite（默认） | 可选 MySQL（见 §6） |
| STATIC_URL/ROOT | `/static/` | 生产 `collectstatic` |

## 5. 可选：MySQL 切换

1. `pip install mysqlclient`（Windows 用 `pip install mysqlclient` 官方 wheel）；
2. settings 中按环境变量切换：

```python
import os
if os.environ.get("DB_ENGINE") == "mysql":
    DATABASES = {
        "default": {
            "ENGINE": "django.db.backends.mysql",
            "NAME": os.environ["DB_NAME"],
            "USER": os.environ["DB_USER"],
            "PASSWORD": os.environ["DB_PASSWORD"],
            "HOST": os.environ.get("DB_HOST", "127.0.0.1"),
            "PORT": os.environ.get("DB_PORT", "3306"),
        }
    }
```

3. 重新执行 `migrate` 与 `seed_data` 即可。

## 6. 生产/部署（可选参考）

| 场景 | 方案 |
| --- | --- |
| 局域网演示 | Waitress：`pip install waitress` → `waitress-serve --port=8000 config.wsgi:application` |
| Linux 服务器 | Gunicorn 4 workers + Nginx 反代 + 静态文件服务：`gunicorn config.wsgi:application -w 4 -b 127.0.0.1:8000` |
| 静态资源 | `python manage.py collectstatic --noinput`，Nginx 指向 `STATIC_ROOT` |

## 7. 常见问题（FAQ）

| 问题 | 处理 |
| --- | --- |
| `python` 不是内部或外部命令 | Python 未加入 PATH，用 `py -m ...` 或重装勾选 PATH |
| 提示 Django 未安装 | 未激活虚拟环境或未执行 `pip install -r requirements.txt` |
| `migrate` 报错（表已存在） | 删除 `db.sqlite3` 后重新 `migrate`（开发期）；生产环境走 `makemigrations` 增量 |
| `runserver 0.0.0.0` 拒绝连接 | `ALLOWED_HOSTS` 加入对应 IP |
| 后台登录失败 | `createsuperuser` 未执行或密码错误 |
| 端口占用 8000 | `runserver 8080` 换端口 |
| seed_data 命令不存在 | 确认位于项目根目录且已在 `config/settings.py` 的 INSTALLED_APPS 包含 `content` |
