| --- | --- |
| 文档编号 | CMS-REQ-001 |
| 版本 | V2.0 |
| 编写人/评审人 | 学生填写 |
| 基线日期 | 2026-08-15 |

## 1. 目标与边界

系统服务于课程演示，管理员在 Django Admin 中管理用户、栏目和文章；匿名用户和普通用户在前台浏览已发布文章并执行组合查询。系统固定使用 PostgreSQL 18.6，Redis 仅保存缓存和限流状态。系统不提供注册、评论、富文本、附件或第三种可见角色。

## 2. 角色

| 角色 | 权限 |
| --- | --- |
| 匿名用户 | 浏览首页、栏目、文章详情与查询 |
| 普通用户 | 登录、退出及全部公开功能；不能进入管理后台 |
| 管理员 | `is_staff=True` 且 `is_superuser=True`；管理用户、栏目、文章和日志 |

## 3. 功能需求

| 编号 | 需求 | 可验收结果 |
| --- | --- | --- |
| FR-CAT | 栏目 CRUD | 名称唯一；有文章的栏目删除被保护 |
| FR-ART | 文章 CRUD 与草稿 | 标题/正文不能只含空白；草稿不公开 |
| FR-UI | 官网式公开浏览 | 首页、列表、详情具有语义标题和响应式布局 |
| FR-SRCH | 三种组合查询 | 题目、上海自然日日期、栏目按 AND 组合；非法输入无 500 |
| FR-AUTH | 登录与权限 | 普通用户没有后台入口；管理员可进入 `/admin/` |
| FR-LOG | 审计与系统日志 | Django 管理审计只读；近期 JSONL 请求日志可筛选 |
| FR-DEMO | 可复现数据 | 两次 `seed_data` 后为 8 栏目、36 文章、3 草稿、4 用户 |
| FR-DEPL | 可复现部署 | Compose 健康后迁移、验证数据库、种子和静态收集成功 |

## 4. 非功能需求

- 正确性：公开查询只访问已发布数据，日期边界包含起止日，稳定排序为发表时间倒序和主键倒序。
- 性能：使用 `item_pub_time_idx`、`item_cat_pub_time_idx`、`item_title_trgm_idx`，由扩展数据下的 `EXPLAIN` 验证。
- 安全：ORM 参数化、模板转义、CSRF、仅超级用户后台入口、密码不记录进日志或文档。
- 可维护性：Ruff、BasedPyright、Django checks、迁移检查、自动化测试和覆盖率门禁。
- 可追溯性：需求、设计、测试、人工验收与符合性矩阵关联。

## 5. 验收范围

验收需覆盖匿名浏览、三种单独和组合查询、普通用户登录退出、管理员后台 CRUD、草稿发布转换、栏目保护删除、审计与系统日志筛选，以及桌面和移动端布局。细则见 `docs/10_人工验收流程.md`。
