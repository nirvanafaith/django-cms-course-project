# PostgreSQL CMS 人工验收流程

## 1. 前置条件

启动 Compose Web 服务，确认 `/health/live/` 与 `/health/ready/` 成功。验收使用匿名窗口、普通用户和管理员三种状态；密码由当前环境变量设置，不写入本流程。

## 2. 公开功能

1. 访问 `/`，确认本地校名标识、五张本地轮播图、语义分区、页脚声明和无横向滚动。
2. 在 `/search/` 分别执行题目、日期、栏目查询，再执行三条件组合；确认结果、错误提示和分页条件保留。
3. 打开文章详情，确认已发布内容可见；草稿和不存在主键均得到公开不可见结果。
4. 在 1440px、768px、375px 验证导航、轮播暂停/前后切换/方向键、移动菜单和图像比例。

## 3. 身份与管理

1. 匿名页面显示登录，不显示后台入口。
2. 普通用户登录、退出，确认无后台入口且访问 `/admin/` 不获得管理权限。
3. 管理员登录，确认前台显示管理入口，进入 `/admin/`。
4. 创建、编辑、发布、撤回和删除一篇测试文章；确认公开可见性变化。
5. 创建栏目、尝试删除含文章栏目并确认阻止；删除空测试栏目。
6. 修改用户普通/管理员角色并确认前台导航与 Admin 权限同步。
7. 在管理审计和系统日志页筛选记录，确认只读边界和敏感数据缺失。

## 4. 证据记录

截图保存于 `docs/evidence/`，命名包含页面、角色和视口。记录操作时间、路由、输入条件、可观察结果和对应截图；禁止把密码、Cookie、令牌或完整查询串写入证据。Task 13 完成后，测试报告登记最终路径与通过数。
