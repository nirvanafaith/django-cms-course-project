## 1. 系统概述

### 1.1 系统构成

| 部分 | 入口 | 使用者 | 功能 |
| --- | --- | --- | --- |
| 前台 | `http://127.0.0.1:8000/` | 所有人 | 浏览栏目与文章、三种模式查询、分页 |
| 后台 | `http://127.0.0.1:8000/admin/` | 管理用户（is_staff） | 栏目/文章增删改查、发布状态、批量操作 |

### 1.2 角色与权限

| 角色 | 权限 |
| --- | --- |
| 普通用户 | 浏览已发布文章；按题目/时间/栏目查询；查看详情 |
| 管理用户 | 上述全部 + 登录后台，管理栏目与文章（含草稿） |

> 草稿（未发布）文章对普通用户完全不可见（详情视同不存在），仅管理用户在后台可见可编辑。

## 2. 启动与访问

### 方式一：一键启动（推荐）

双击项目根目录的 **`启动系统.bat`**，脚本自动完成：
1. 检查虚拟环境与 Django 依赖；
2. 执行数据库迁移（幂等，可重复）；
3. 初始化演示数据（已存在则跳过）；
4. 启动服务（窗口保持打开，日志可见）；
5. **3 秒后自动打开默认浏览器**访问前台首页。

### 方式二：命令行启动

```powershell
cd cms_site
.\.venv\Scripts\activate
python manage.py runserver
```

浏览器访问：
- 前台首页：http://127.0.0.1:8000/
- 后台管理：http://127.0.0.1:8000/admin/

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理用户 | admin | admin123456 |

## 3. 前台操作指南（普通用户）

新版前台顶部导航会标识当前页面。移动设备上点击右上角菜单按钮可展开首页、全部文章和搜索入口。首页欢迎区提供“浏览全部文章”和“搜索文章”两个直接入口。

查询页会在结果上方显示当前栏目和结果数量；查询面板支持题目、起止日期和栏目组合筛选。栏目选择中的“全部栏目”表示不按栏目过滤。无结果时可选择“清除条件”或“查看全部文章”恢复浏览。

### 3.1 首页浏览

首页包含：
- **栏目导航卡片**：显示各栏目名称与文章数，点击卡片进入该栏目文章列表；
- **最新文章列表**：最近发布的 8 篇已发布文章，点击标题进入详情。

### 3.2 查看文章详情

- 在首页/列表/搜索结果的任意标题点击，进入详情页；
- 详情页显示：标题、所属栏目、发表时间、作者（如有）、正文；
- 页面底部提供「← 返回该栏目」按钮。

### 3.3 按栏目浏览文章

- 方式一：首页点击栏目卡片；
- 方式二：顶部导航「全部文章」后，在左侧查询面板「栏目」下拉中选择；
- 列表按发表时间倒序排列，每页 10 条。

### 3.4 查询文章（三种模式 + 组合）

查询面板位于列表/搜索页左侧（或顶部搜索框），支持：

| 模式 | 输入 | 示例 | 说明 |
| --- | --- | --- | --- |
| ① 按题目 | 题目关键词 | `Python` | 标题包含关键词即命中（不区分大小写）；≤100 字符 |
| ② 按发表时间 | 起始/结束日期 | `2024-01-01` | 格式严格 `YYYY-MM-DD`；可只填起始或只填结束 |
| ③ 按栏目 | 下拉选择栏目 | 教学动态 | 下拉列出全部栏目 |
| 组合 | 上述任意组合 | q + 栏目 | 多条件同时满足（AND） |

操作步骤：
1. 进入「搜索」页（顶部导航）或任意列表页左侧面板；
2. 填写一个或多个查询条件；
3. 点击「查询」按钮；
4. 结果按发表时间倒序分页显示，每页 10 条。

**输入规范与提示**：

| 情况 | 系统行为 |
| --- | --- |
| 日期格式错误（如 `2026-13-45`） | 显示"日期格式应为 YYYY-MM-DD"，不报错 |
| 开始日期晚于结束日期 | 显示"开始日期不能晚于结束日期" |
| 关键词超 100 字符 | 提示长度限制 |
| 无匹配结果 | 显示"没有找到相关文章" |
| 非法页码（0/-1/非数字） | 自动回到第 1 页 |
| 页码超界（如 99） | 自动跳到最后一页 |

### 3.5 分页浏览

- 结果超过 10 条时底部出现页码条（上一页/页码/下一页）；
- 翻页后**查询条件自动保留**（如带关键词翻页，链接仍携带该关键词）。

## 4. 后台操作指南（管理用户）

后台仍为原生 Django Admin，登录、权限、CRUD、筛选和批量操作方式不变。本轮仅统一颜色、排版、表单、按钮、消息和焦点样式，不新增另一套管理界面。

### 4.1 登录与登出

1. 访问 `http://127.0.0.1:8000/admin/`，未登录自动跳转登录页；
2. 输入管理账号与密码登录；
3. 右上角可登出。

### 4.2 栏目管理

**新增栏目**：栏目列表页右上角「增加 栏目」→ 填写名称（必填、唯一）、简介（可选）→ 保存。

**修改栏目**：点击栏目名进入编辑页 → 修改 → 保存。

**删除栏目**：
- 栏目下**无文章**时：可直接删除；
- 栏目下**有文章**时：系统阻止删除并提示"该栏目下存在文章，无法删除"——需先删除或移走该栏目文章。

### 4.3 文章管理

**发布新文章**（对应题目要求"管理用户发布文章、选择栏目"）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | ✅ | ≤200 字符 |
| 正文 | — | 可为空 |
| 所属栏目 | ✅ | 从现有栏目中选择 |
| 发表时间 | ✅ | 默认当前时间，可修改 |
| 发布状态 | — | 勾选=已发布（前台可见）；不勾=草稿（前台不可见） |
| 作者 | — | 可选，默认当前登录用户 |

操作：文章列表页 →「增加 文章」→ 填写 → 保存。

**修改文章**：点击标题 → 修改 → 保存；修改后前台立即显示新内容。

**删除文章**：选中后执行删除（二次确认）→ 前台列表/详情立即消失（404）。

**发布状态控制**：
- 单篇：编辑页勾选/取消「发布状态」；
- 批量：列表勾选多篇 → 下拉选择「设为已发布」或「设为草稿」→ 执行。

### 4.4 后台查询辅助

| 功能 | 位置 | 说明 |
| --- | --- | --- |
| 按发布状态过滤 | 文章列表右侧 | 全部/已发布/草稿 |
| 按栏目过滤 | 文章列表右侧 | 各栏目 |
| 按时间过滤 | 文章列表右侧 | 任意日/月/年 |
| 按标题搜索 | 列表上方搜索框 | 标题关键字 |
| 日期层级 | 列表顶部 | 按年→月→日下钻浏览 |

### 4.5 权限说明

- 仅 `is_staff` 管理用户可登录后台；普通账号登录后被拒绝；
- 未登录访问后台自动跳转登录页。

## 5. 常见问题（FAQ）

| 问题 | 处理 |
| --- | --- |
| 忘记管理密码 | `python manage.py createsuperuser` 重新创建或重置 |
| 前台看不到刚发的文章 | 检查文章「发布状态」是否勾选（草稿前台不可见） |
| 无法删除栏目 | 栏目下仍有文章，先删除/移走文章（FR-CAT-03 数据保护） |
| 查询无结果 | 更换关键词；确认日期格式 `YYYY-MM-DD`；确认栏目选择 |
| 后台报 403 | 账号无管理权限（需 is_staff）；或 CSRF 过期，刷新页面重试 |
| 端口被占用 | `python manage.py runserver 8080` 换端口 |
| 如何重置演示数据 | 删除 `db.sqlite3` → `migrate` → `seed_data`（幂等可重复） |
